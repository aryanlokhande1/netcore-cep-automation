Coordinates are relative to that image, not a guessed desktop position.

## General dropdown procedure

1. Observe the actual dropdown control in the current stage.
2. Inspect its current state and ownership.
3. Click the observed dropdown to open it when needed.
4. Observe again to obtain actual rendered options.
5. Use options to inspect exact existing matches.
6. If a reviewed owned search field exists, search there.
7. Reobserve the resulting options; search text is not selection.
8. Select one exact approved existing option.
9. Reobserve and verify the actual selected value.
10. If ownership or exact identity is ambiguous, retain uncertainty.

Do not count a dropdown-opening click as selected-state verification.
Do not count an SDK return as a successful selection.
Do not create tags or choose a create-new option.
Native selects use their actual observed option values.
Custom options must belong to the observed control and reviewed existing list.
If an unfamiliar widget is unresolved, inspect current DOM and visual evidence.
If that evidence remains insufficient, hand the actual blocker to Observer.

## Recovery and STUCK

Read the tool result and Observer feedback before another action.
For a safe UI failure, try a materially different supported preparation/method.
Examples are fresh DOM inspection followed by authorized visual inspection.
For an offscreen target, inspect, scroll, then reobserve before interacting.
Repeated clicks on the same failing target are not distinct approaches.
Two distinct valid failed approaches normally produce structured STUCK.
Count only failed supported approaches on the same unresolved field since real progress.
Verified dropdown opening, search readback and changed scroll position are progress.
INCOMPLETE with progress returns to the Doer for inspection/selection/readback.
The controller may stop earlier for unsafe actions or exhausted budgets.
Never retry uncertain writes, credentials, changed identities or security failures.
Report tool/executor defects as CODE_FIX_REQUIRED, not a prompting problem.
Retain the last verified milestone and remaining unresolved predicates.
