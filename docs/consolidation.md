# Repository consolidation report

Date: 12 November 2026. Scope: audit, recoverable cleanup, operational documentation,
packaging/ignore hygiene and offline/local-browser validation. No runtime redesign.

## Issues and decisions

The pre-cleanup inventory contained 3,945 non-private/non-cache files (77.65 MB),
152 Python files including six one-off output helpers, 30 documentation artifacts
and 3,155 files under outputs. README claims and example comments referred to
early implementation stages, omitted current WhatsApp capabilities, and stated
obsolete Teacher budgets. Repair reports overlapped without a canonical operating
guide. Generated WhatsApp drafts/legacy reports were not fully ignored.

Static dependency/reference audit found both modern and legacy CLI runtimes still
reachable. No source module was proven dead. Current baseline and legacy Setup
validators have different contracts, so merging them would be a behavior change.
No redundant security scan was proven safely removable. There was no source-code
cleanup justified merely by an old filename.

Five existing directly imported dependencies were declared explicitly at their
already-locked versions: langchain, langchain-core, langsmith, PyYAML, tiktoken.
No new package was installed. Explicit-package discovery now avoids treating
artifact directories as namespace packages. Login skill Markdown joins existing
Deep Agents prompt package data. Deployment still assumes a writable checkout.
